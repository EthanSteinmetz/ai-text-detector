Objective

Building a Portfolio From Scratch

This project simulates the process a portfolio manager or individual investor would follow to construct, monitor, and rebalance a multi-asset portfolio. Starting with a hypothetical $10,000 investment budget, I developed an investment thesis, selected positions, tracked performance, and applied quantitative risk metrics including beta, Sharpe ratio, and correlation analysis.

The portfolio targets a blend of growth equity, dividend income, broad index exposure, and a small defensive allocation in gold and long-duration treasuries. Historical price data was pulled via the Yahoo Finance API using Python.

Portfolio Mandate: Achieve long-term capital appreciation with moderate risk. Target: outperform the S&P 500 on a risk-adjusted basis over a 12-month simulation period. Maximum single-position concentration: 20%.

Tools Used

Python (pandas, NumPy) Yahoo Finance API (yfinance) Microsoft Excel Matplotlib / Seaborn Jupyter Notebook

Key Finance Concepts

  • Asset allocation and diversification across asset classes
  • Beta — measuring portfolio sensitivity to market moves
  • Sharpe ratio — return per unit of risk (volatility)
  • Correlation matrix — identifying diversification benefits
  • Performance attribution — which holdings drove returns
  • Rebalancing — managing drift from target weights
  • Maximum drawdown — understanding downside exposure

Methodology

Portfolio Construction Process

01

Define Investment Mandate & Constraints

Established portfolio objectives (capital appreciation), risk tolerance (moderate), time horizon (12 months), and position constraints (max 20% in any single name, minimum 2 positions per asset class).

02

Develop Investment Thesis for Each Position

Wrote a one-paragraph rationale for each of the 8 positions, covering the fundamental driver, valuation context, and expected return contribution. No position was included without a clear thesis.

03

Build the Tracking Model in Python

Used yfinance to pull 12 months of daily adjusted close prices. Calculated daily returns, cumulative returns, and rolling volatility for each position and the aggregate portfolio.

04

Calculate Risk Metrics

Computed portfolio beta using OLS regression against SPY, annualized Sharpe ratio (using 3-month T-bill as risk-free rate), maximum drawdown, and a full 8x8 correlation matrix across all positions.

05

Monthly Rebalancing & Performance Review

Simulated monthly rebalancing back to target weights. Tracked performance attribution — how much of the total return came from each position — and compared portfolio performance against the SPY benchmark.

What I Learned

Key Takeaways

Diversification Has Limits

My "defensive" TLT position dragged on returns. Duration risk is real — bonds don't always hedge equities in a rate-rising environment.

Risk-Adjusted Returns

A higher raw return doesn't always mean better performance. The Sharpe ratio showed our alpha was partly consumed by higher volatility from the growth-heavy tilt.

Attribution Analysis

AMZN contributed 213 bps while TLT cost 47 bps. Performance attribution teaches you what's working — and forces accountability for every position.

Behavioral Discipline

Simulating monthly rebalancing despite short-term noise revealed how hard it is to stick to a process when individual positions are moving violently.

Why It Matters for Finance

Core to Buy-Side & Wealth Management

Portfolio construction, risk management, and performance attribution are the fundamental activities of buy-side professionals — portfolio managers, analysts, and risk officers at hedge funds, mutual funds, endowments, and wealth management firms.

This project provides hands-on familiarity with concepts that are often discussed abstractly in finance courses but that matter practically when managing real capital. Understanding the tradeoff between return, volatility, and diversification is prerequisite knowledge for any markets-facing role.

It also demonstrates programming proficiency (Python, pandas) for data-driven financial analysis — an increasingly expected skill at leading buy-side shops and trading desks.
